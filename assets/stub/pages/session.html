M8 — THE SESSION KEEPER

sessionStorage

The same key/value API as localStorage, with a different lifetime: it belongs to this tab, and it is never written to disk. Close the tab and it is gone; open a second tab and it starts empty.

…

Everything sessionStorage holds right now. It is scoped to the origin this site and to this tab — a second tab on the same site has its own, separate sessionStorage, so two tabs never see each other’s here.

local vs session

localStorage: shared by every tab on the origin, persisted to disk, no expiry. sessionStorage: private to one tab, in memory only, cleared when the tab closes. Same methods (getItem/setItem/removeItem/clear/length/key), same 5 MB-ish quota, same QuotaExceededError on overflow — only the lifetime differs.
