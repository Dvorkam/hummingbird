M8 — THE SESSION KEEPER

localStorage

A per-origin key/value store the page's own JavaScript owns. Unlike a cookie it is never sent to a server, and unlike a session cookie it has no expiry — it lives until the page clears it.

Everything localStorage holds for this exact origin (this site). A different scheme, host, or port gets a separate store — stricter than a cookie, which ignores scheme and port. Storage on the cookie demo is the same origin, so anything set there shows here too.

What it is not

It is capped at about 5 MB per origin; a write past that throws QuotaExceededError rather than silently dropping. It is stored in plain text in the profile directory — fine for preferences, not a place for secrets. And it never expires on its own, which is exactly why the cap matters.
