M8 — THE SESSION KEEPER

Remembering things between requests

Milestone 8 gives the browser a memory: a cookie jar that survives a restart, and enough of a multiline text control to write something worth sending.

Cookies

A jar wired into every request, with domain and path matching, expiry, Secure, HttpOnly and SameSite — persisted to disk so a session outlives the process.

Open the live cookie demo »

Counts your visits using nothing but the jar, shows the exact Cookie header the browser sent next to what document.cookie is allowed to see, and survives closing the browser.

localStorage

A per-origin key/value store the page’s own JavaScript owns — never sent to a server, no expiry, persisted to disk with a 5 MB cap.

Open the localStorage demo »

Counts how many times you have loaded the page using nothing but localStorage, and survives closing the browser — the count keeps climbing.

Textarea

A deliberately narrow multiline control: enough to type a comment and submit it, which is what the Hacker News proof target needs.

Focus the field, type, use Enter for a new line, and submit to see the name=value payload. It arrives prefilled, so it also shows a textarea’s content becoming its default value with character references decoded and markup left literal. Selection, clipboard, wrapping, scrolling, resize, and the general textarea DOM APIs remain M11 follow-ups.
