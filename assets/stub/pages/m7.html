M7: External Script Loading (7.0.1)

« back to example.dev

Document-order execution: inline -> external -> inline

Three <script>s run in the order they appear in the HTML. The middle one is a separate file (m7.js) fetched through the resource pipeline before any script runs.

1. inline script before the external one: pending…

2. external m7.js: pending… (if this line never changes, the fetch or eval failed)

3. inline script after the external one: pending…

Last script to run: none yet

load event: pending…

Expected when everything works: all three steps show [OK], the “last script” line says inline #2 (it runs after m7.js in document order — if it said external m7.js, ordering would be broken), and the load event fired last.

What is new here

Before M7, only inline <script> bodies ran — the src attribute was ignored entirely. Now external scripts are fetched as a first-class resource type and the whole set (inline and external, interleaved) executes in document order, with the load event held back until every script has run.

Skipped by design on this page: a <script type="application/json"> data block would not execute, and a failed fetch would be skipped while the remaining scripts still run.
