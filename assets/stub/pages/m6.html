In a wide box the modes render distinctly: contain fits the whole logo inside (small, letterboxed); 100% scales it to the box width keeping aspect ratio (larger, cropped top/bottom); 100% 100% stretches it to fill both axes (distorted). The background: … center/100% shorthand (right) parses the /size syntax and so matches the 100% box — the fix behind DDG's round, centered logo.
