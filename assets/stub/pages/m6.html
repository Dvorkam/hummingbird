Added in M6: display: flex, flex-direction (+reverse), justify-content, align-items, flex-grow/shrink/basis, the flex shorthand, order, and flex-wrap (+ wrap-reverse); float clear; plus CSS control-chrome compat — per-corner border-radius, per-side border-color, vendor-prefixed aliases, and percentage background-size; and align-items: baseline. Also a legacy compatibility slice — visibility, pointer-events, text-shadow, and legacy clip: rect(...) — and vendor-prefixed properties we do not implement are now dropped silently instead of warning. Additive calc() (percentage ± px) resolves at layout time, and visited links (:visited / vlink) style from navigation history. Rounding out the milestone: @font-face web fonts (local + remote TTF/OTF) and a display: grid MVP (tracks, fr/repeat(), gaps, and line/span placement).

Visited link state

example.dev (you navigated here from it, so it renders :visited purple) — a fresh link (default link blue — click it, then come back, and it turns purple).

The engine records every navigated URL; an anchor whose href resolves to a visited URL matches :visited and takes the vlink color (here forced purple via a:visited). Both links go to real pages you can return from.

calc() length expressions

width: calc(100% - 40px)
width: calc(50% + 40px)

Widths mix a percentage of the container with a px offset, resolved at layout time. The dark bar stops 40px short of the track's right edge; the green bar is half the track plus 40px. Multiplication, nested calc(), and calc() with var() are not yet supported (those declarations are dropped).

@font-face web font

The quick brown fox jumps over 1234567890.

This line uses font-family: "Webfont Demo", a name with no built-in mapping. An @font-face rule points that family at a bundled RobotoMono file, so the text renders in that (monospaced) font instead of falling back to the sans body font. Local url() sources load synchronously; remote src urls are fetched through the resource pipeline (raw TTF/OTF only — WOFF2 needs a decoder, filed as T-FONT-WOFF2-1).
