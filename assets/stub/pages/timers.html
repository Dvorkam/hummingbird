Time now exists

Before M7 there was no clock: setTimeout and setInterval did not exist, so nothing could run "later". These readouts are driven by real timers firing on the main-loop tick.

What to look for

The first number climbs by one every second and never stops. The countdown counts 5,4,3,2,1,0 then freezes because its callback calls clearInterval on itself. The one-shot line changes exactly once, three seconds after load. Clicking the button flips the ticking timer on and off via clearInterval / setInterval.

Navigating away cancels every timer on this page (timers die with the document), so nothing leaks into the next page.
