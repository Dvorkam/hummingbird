Asking the network for itself

Milestone 9 gives the page its own voice on the network: fetch(), a CORS model, and an HTTP cache. It starts with the two event-loop guarantees everything promise-based rests on.

Event-loop ordering

A promise continuation runs when the JavaScript stack empties — not when some inner handler happens to return. Clicking below runs a handler that queues a .then, then calls focus(), which fires a nested focus handler while the click handler is still running.

Per-document JavaScript isolation

Each navigated document gets a fresh JavaScript global. A variable one page leaves on globalThis is invisible to the next page in the same tab, even though they share one engine.
